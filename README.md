# 🔐 Dark Web URL Classifier

A deep learning-based web application that classifies URLs into four categories:

- ✅ Benign
- 🎣 Phishing
- 🦠 Malware
- ⚠️ Defacement

## 🛠 Technologies Used

- Python
- Streamlit
- TensorFlow
- Keras
- NumPy
- Scikit-learn
- NLTK

---

## ▶️ How to Run Locally

```bash
git clone https://github.com/vaishnavidarisipudi/DarkWeb-URL-Classifier.git

cd DarkWeb-URL-Classifier

pip install -r requirements.txt

streamlit run app.py
```
